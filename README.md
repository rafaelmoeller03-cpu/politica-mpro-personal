## 📱 Sobre o aplicativo

O **M-PRO Personal** é um aplicativo voltado para personal trainers, permitindo:

- Gerenciamento de alunos
- Criação de treinos personalizados
- Acompanhamento de evolução física
- Registro de histórico de treinos
- Organização de dados de forma offline

---

## 🔒 Privacidade

- Todos os dados são armazenados localmente no dispositivo
- O aplicativo funciona principalmente offline
- Não há compartilhamento de dados com terceiros

---

## 💳 Assinaturas

- Funcionalidades premium podem ser oferecidas via Google Play
- As assinaturas são gerenciadas pela própria Google

---

## ⚠️ Aviso Importante

O aplicativo não substitui acompanhamento médico, nutricional ou clínico.
